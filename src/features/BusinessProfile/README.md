# معرفی کسب‌وکار

مسیر عمومی و مستقل از MainLayout:
/business/:slug

تا آماده‌شدن بک‌اند، صفحه به‌صورت پیش‌فرض اطلاعات نمونه طرح نمونه را از data/demoProfile.ts نمایش می‌دهد و هیچ درخواست API ارسال نمی‌کند. برای مشاهده، مسیر /business/mohammadnia را باز کنید.
بنر و نقشه نمونه از تصویر طرح استخراج شده‌اند؛ لینک‌های شبکه‌های اجتماعی نمونه هستند و به حساب واقعی اشاره نمی‌کنند.
برای فعال‌کردن API پس از تأیید قرارداد واقعی، متغیر VITE_BUSINESS_PROFILE_USE_API=true را تنظیم و پروژه را مجدداً اجرا یا build کنید.
هوک دریافت اطلاعات و مدیریت عنوان صفحه در Hooks/useBusinessProfile.ts و endpoint در reducers/endpoints.ts قرار دارد.

## قرارداد پیشنهادی API (نیازمند تأیید بک‌اند)

آدرس فعلی: GET {baseUrl}/Business/GetBySlug?slug={slug}

این آدرس از قرارداد موجود در مخزن تأیید نشده است؛ پس از دریافت مستندات بک‌اند، endpoint و در صورت نیاز transformResponse باید مطابق قرارداد واقعی تنظیم شوند.
از baseApi و store موجود استفاده شده و هیچ API یا store موازی ایجاد نشده است.
پاسخ مطابق IResponse پروژه، شامل Status: true و Data با ساختار BusinessProfile در types.ts است.
name و introduction رشته و phones آرایه رشته هستند؛ سایر فیلدها اختیاری‌اند.
HTTP 404 حالت پیدا نشدن را نشان می‌دهد؛ خطاهای دیگر دکمه تلاش مجدد دارند.
تصاویر، بنر، نقشه، لینک بنر و شبکه‌های اجتماعی به ازای هر کسب‌وکار از پاسخ دریافت می‌شوند.
تصویر نقشه باید یک تصویر واقعی باشد؛ link آن آدرس سرویس نقشه برای بازکردن موقعیت است، نه iframe.
فقط لینک‌های کامل http/https پذیرفته می‌شوند. شماره‌های فارسی برای لینک tel تبدیل می‌شوند.
تصویر عمومی فروشگاه و آیکن‌های شبکه‌های اجتماعی از طرح ارسالی استخراج شده‌اند؛ اطلاعات اختصاصی هیچ کسب‌وکاری در صفحه ثابت نشده است.

## بررسی

npx vitest run src/features/BusinessProfile

npm run build

برای بررسی بصری بدون بک‌اند، حالت پیش‌فرض نمونه شامل متن‌ها، بنر، نقشه و شبکه‌های اجتماعی طرح است.
