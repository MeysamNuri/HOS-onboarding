# Frontend Portfolio — React / TypeScript

نسخه مستقل و پاک‌سازی‌شده برای نمایش معماری و رابط کاربری پروژه.
این نسخه به سامانه واقعی شرکت متصل نمی‌شود و آمار صفحه فرود ساختگی است.

## اجرا

نیازمندی پیشنهادی: Node.js 24 و npm. تست نهایی با Node.js 24.18.0 انجام شده است؛ ابزار تست حداقل Node.js 22.12 در شاخه 22 را نیاز دارد.

```sh
npm ci --legacy-peer-deps --ignore-scripts
npm run dev
```

صفحه اصلی: `http://localhost:8080/holoo-sendLink-landing`

```sh
npm run build
npm run vitest -- run
npm run security:check
```

پرچم legacy-peer-deps به دلیل ناسازگاری peer dependency موجود بین antd و antd-jalali-plus است؛ این پرچم به معنی تأیید سازگاری آن‌ها نیست.

## ساختار و قابلیت‌ها

- React 19، TypeScript، Vite، Redux Toolkit Query و React Router
- رابط فارسی و RTL، صفحات فرود واکنش‌گرا، کارت‌ها و اسلایدرها
- ساختار feature-based و تست‌های Vitest / Testing Library
- داده ساختگی محلی برای آمار لندینگ و fallback بسته‌ها

## محدودیت نسخه نمایشی

ورود، پرداخت، فعال‌سازی، اطلاعات کاربران و سایر عملیات سرور عمداً غیرفعال‌اند.
پیوندهای بیرونی با دامنه غیرواقعی جایگزین شده‌اند؛ ویدئوها و PDFهای بیرونی نمایش داده نمی‌شوند.
تصاویر فاکتور، اسکرین‌شات‌های دارای احتمال اطلاعات شخصی و تصاویر جاسازی‌شده با جایگزین خنثی عوض شده‌اند؛ بنابراین ظاهر بعضی بخش‌ها عمداً با نسخه اصلی متفاوت است.
فونت تجاری از خروجی حذف شده و فونت جایگزین سیستم استفاده می‌شود؛ ظاهر متن ممکن است متفاوت باشد.
کد PWA برای مطالعه باقی مانده ولی ثبت service worker در این خروجی خاموش است.
این خروجی بک‌اند، حساب آزمایشی یا رمز ورود ندارد و نسخه production-ready نیست.

## انتشار در GitHub

1. ابتدا مجوز انتشار سورس و دارایی‌های شرکت را بگیرید؛ تصاویر و نشان‌های تجاری هنوز در پروژه وجود دارند.
2. ZIP را استخراج کنید و محتوای پوشه frontend-portfolio را در یک مخزن جدید آپلود کنید؛ خود ZIP جایگزین مخزن سورس نیست.
3. پوشه .git پروژه اصلی، node_modules، dist، فایل‌های .env و لاگ‌ها را منتقل نکنید.
4. فایل SECURITY.md و گزارش RELEASE-CHECKS.md را بخوانید.
5. این پروژه از BrowserRouter استفاده می‌کند؛ میزبانی باید fallback مسیرها به index.html داشته باشد. GitHub repository به‌تنهایی اجرای زنده برنامه نیست.

هیچ مجوز متن‌باز جدیدی به کد یا دارایی‌ها نسبت داده نشده است. نبودن اطلاعات ورود، به معنی داشتن اجازه انتشار نیست.
